# Design system

## Accepted language

User-provided seed layout: title/menu header; large central editable quanta; mobile upward rail to send; desktop full-width Tunnel action and Ctrl+Enter; attachment and clipboard actions below; history and pairing on separate pages. Orbit/particle motifs, send motion and restrained typography express tunneling. Attachment opens a file picker. Composer attachments occupy an internal bottom carousel with integrated thumbnail, filename, size and removal control; text becomes an optional note. History uses coherent media cards with separated actions rather than floating images. Desktop offers Copy/Save and a complete-quanta dialog; text remains selectable. Mobile image taps open a viewer with separate touch-sized Save and Share controls. Mobile now launches after a short upward flick or two-particle distance, animating to the top; its side rail is 56 dp wide and spans the composer and action row. Appearance offers Left/Right/Under, with Slider/Button for Under; the horizontal rail moves left to right. A completion burst/fade precedes an invisible reset. Header-to-content padding and a smaller, narrower multi-line empty prompt restore breathing room. Save Name has pressed/saving/saved feedback, the menu opens without a slow modal transition, and the snackbar adjusts for the keyboard. Android Back first dismisses input focus/menu/camera, then follows navigation history to Tunnel, then lets Android exit. Desktop uses a persistent left sidebar and searchable recent history on the right. Received/Sent/All filters default to Received.

[Runtime themes](../../packages/shared/src/theme.ts) own Mineral sage/teal, Dune warm sand and Tide cool blue, each with light/dark variants and system selection. Mineral light is the default. Dark surfaces are softened green slate, avoiding near-black. Theme switching preserves draft/navigation. Exact colors belong in source, not screenshots. The launcher [atom source](../../assets/tunnel.svg) matches the in-app Orbit on off-white; [adaptive foreground](../../assets/tunnel-foreground.svg) and [icon manifest](../../assets/icon-manifest.json) reproduce native outputs with Tauri icon.

## Composition and primitives

[Web CSS](../../apps/desktop/src/style.css) owns typography, spacing, rounded composer, rail, navigation, cards and feedback using Aurora CSS roles. DM Sans provides interface text, Instrument Serif the identity/editorial accent; fonts ship locally. [Mobile token mapping/styles](../../apps/mobile/src/TunnelApp.tsx) mirrors the same semantic hierarchy with native components. The native rail owns gesture progress, cancellation, momentum and accessible actions; desktop has no rail. Mobile adds haptics and reduced-motion handling; web uses reduced-motion CSS.

The home has no promotional heading or blank-space footer. [Composer copy](../../packages/shared/src/composer.ts) includes the original “Ready to stochastically appear somewhere else?” and cycles on home/app return and confirmed send. Full-history subtitle is “All quanta you've tunneled”. Receipts on both visible apps trigger a viewport-wide orbit/ripple pulse, respecting reduced motion. The mobile receipt snackbar opens history. Desktop composer and recent-history columns share the same bottom edge; recent heading/View all and filter/search each share a row. Scrollbars are hidden while scrolling remains available. The Android adaptive icon foreground scale is 60% to keep the atom inside its container.

States include disconnected/connecting/connected, empty/ready composer, sending, delivered/failed history, QR expiry, revoked link and clipboard errors. Connection/receipt feedback must remain accurate. [Theme tests](../../tests/theme.test.ts) cover completeness/readability; automated checks do not establish user comfort or actual OS interaction. Earlier visual observations are historical [verification](../../docs/verification.md), with new visual assessment left to the user.

Share straight away settings use existing Aurora panels/switches, independently for Text, Images and Other files. Text defaults on; images/files default off for note review. Native intake confirmation uses Android toast/notification and keeps the source app visible; host apps control selected-text action placement.
