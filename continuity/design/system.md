# Design system

## Accepted language

Selected 2026-10-31: [Dusk](dusk-handoff.md) supersedes the editorial header, serif headings, carousel and Save/Share text bars. Android uses four equal bottom tabs: Tunnel, History, Singularity, Settings. Linked devices and Account are Settings pages; Appearance includes Left/Right/Under send controls. Tunnel has no phone title; the Linked pill ends the device-chip row. The large editable composer has four equal icon buttons on Android: Attach, OCR, Camera, Paste. Each is 60 dp tall with an accessible name and the existing soft surface/rounded rectangle treatment. The 56 dp side rail spans the composer and action row. This user-selected extension (2026-11-01) supersedes the study’s two text buttons; desktop retains Attach/Paste. Rail handle is 34×48 with a 20 dp radius. Short flick/two-particle send, completion burst/reset, receipt feedback, persisted destinations and draft safety remain. Desktop keeps the full-width Tunnel action/Ctrl+Enter, a Recent column and a 220/76 px sidebar toggled only by the Axis logo. History defaults to Received and retains Received/Sent/All and search.

Image quanta use individually cream-framed prints with a count on the front print. Composer stacks fan; history opens a single-print viewer. Its cream caption band holds previous/next/close, the index and desktop copy. Phone swipes change photos and a 380 ms hold copies; movement beyond 8 px cancels the hold. Download icons save attachments; file rows retain share/copy where supported. Save Name feedback and keyboard-offset messages remain. Android Back dismisses keyboard/modal state before returning through navigation.

Singularity shows Quanta/Spaces with separate search spacing. Desktop raw quanta, spaces and open-space entries use equal-height two-column grids; phone uses one column. A 52 px composer stays below the scrolling list, above phone tabs or 16 px above the desktop bottom. Spaces have no composer until opened. A floating create-space button opens a dialog and hides inside a space; selecting Spaces returns to the list. Move menus escape scrolling cards through a modal/portal layer. Expanding uses two opposing arrows and opens complete selectable text. Phone holds copy and right swipes tunnel text to the selected local destinations without consuming the existing draft. Account lives only under Settings. The account/runtime stays mounted when navigating so callbacks and sync continue.

[Runtime themes](../../packages/shared/src/theme.ts) own Mineral sage/teal, Dune warm sand and Tide cool blue, each with light/dark variants and system selection. Mineral light is the default. Dark semantic surfaces use the Dusk blue slate palette, avoiding near-black. Tide uses the study mint; Mineral keeps a green accent and Dune a peach accent. All three light variants and saved Light/Dark/System preferences remain; no fourth theme or provider is added. Theme switching preserves draft/navigation. Exact colors belong in source, not screenshots. The launcher is Axis, selected 2026-10-26: a Tide split, one horizontal orbit, one upright orbit, and a reversed disc. Construction is [the Axis spec](axis.html). [Source](../../assets/tunnel.svg) and [adaptive foreground](../../assets/tunnel-foreground.svg) are that full-bleed mark; the [icon manifest](../../assets/icon-manifest.json) reproduces the Windows and Android sizes with Tauri icon. The user extended Axis to in-app branding on October 26. Desktop sidebar and empty composer use the source SVG through BrandMark in App.tsx. The mobile empty composer reuses the generated Axis icon.png through BrandMark in TunnelApp.tsx. The marks use a rounded square; the phone empty-composer mark is larger in the Dusk composition. The fixed Tide brand colors remain the same across Aurora themes. Android notifications use a white two-orbit and half-disc variant because Android tints small icons. Arrival feedback and send-rail particles retain their existing motion.

The OCR capture review uses a full-image selection by default, a freely resizable frame with four 48 dp corner targets, a draggable interior, and dimming outside the selection. It fits the whole image without distortion. The right-aligned utility pair uses a camera icon for Retake and a four-corner frame icon for Reset, each with a 48 dp target and explicit accessible name. One SVG even-odd mask shades outside the crop without seams between separate translucent rectangles. Reset restores the full image; Retake returns to capture; the full-width 60 dp Continue action starts OCR and shows progress. Use existing Aurora surfaces, primary accents and DM Sans, without a new theme or shutter flash. Screen-reader adjustment actions move corners/selection. This refinement was selected 2026-11-01; user visual/device acceptance remains pending H17.

## Composition and primitives

[Web CSS](../../apps/desktop/src/style.css) owns typography, spacing, rounded composer, rail, navigation, cards and feedback using Aurora CSS roles. DM Sans provides the Dusk interface text; existing fonts ship locally. [Mobile token mapping/styles](../../apps/mobile/src/TunnelApp.tsx) mirrors the same semantic hierarchy with native components. The native rail owns gesture progress, cancellation, momentum and accessible actions; desktop has no rail. Mobile adds haptics and reduced-motion handling; web uses reduced-motion CSS.

The home has no promotional heading or blank-space footer. Its pale dot lattice stays still; one upward sheen plays on Tunnel entry and mobile rail use, and reduced motion removes it. [Composer copy](../../packages/shared/src/composer.ts) includes the original “Ready to stochastically appear somewhere else?” and remains fixed to that prompt on Android; desktop retains its prompt cycle. Receipts on both visible apps trigger a viewport-wide orbit/ripple pulse, respecting reduced motion. The mobile receipt snackbar opens history. Desktop composer and recent-history columns share the same bottom edge; recent heading/View all and filter/search each share a row. Scrollbars are hidden while scrolling remains available. The Android adaptive foreground fills the mask. The orbits stay inside the safe circle, so the wall can run to the edge.

States include disconnected/connecting/connected, empty/ready composer, sending, delivered/failed history, QR expiry, revoked link and clipboard errors. Connection/receipt feedback must remain accurate. [Theme tests](../../tests/theme.test.ts) cover completeness/readability; automated checks do not establish user comfort or actual OS interaction. Earlier visual observations are historical [verification](../../docs/verification.md), with new visual assessment left to the user.

Share straight away settings use existing Aurora panels/switches, independently for Text, Images and Other files. Text defaults on; images/files default off for note review. Native intake confirmation uses Android toast/notification and keeps the source app visible; host apps control selected-text action placement.

## October 10 refinements

Receipt pulses last about 2.1 seconds; send motion is slower and successful immediate transfers keep sending feedback visible for at least 1.1 seconds. Mobile rail travel is 600 ms, followed by a 320 ms burst/fade and 280 ms reappearance; reduced-motion preference remains respected. The horizontal rail displays larger particles above its transparent, lower label.

Desktop recent controls divide width equally between filter and search. Full-quanta viewing uses the existing fixed, centered modal scrim; the app owns viewport height, with scrolling limited to content panes (narrow stacked layouts can still scroll). Destination chips extend the existing Aurora card/selection vocabulary above the phone composer: persistent multi-selection, named recipients and status dots. Linked devices offers independent unlink and additive QR pairing. Manual comfort/layout assessment remains user-owned.
