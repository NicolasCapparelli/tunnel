# Implementation map

## Setup and resumption

Requests: get this running, rebuild, return after a break, move checkout. Start [setup commands](../developer/setup.md#local-commands) and [stopping point](../status.md#active-work-and-last-stopping-point). Build owner: [desktop helper](../../tools/desktop.ps1); phone owner: [Android helper](../../tools/android.ps1), which refreshes native configuration before builds. `npm run build:android:apk` builds an ARM64 APK without installing or launching it. Verify through [automated commands](../developer/setup.md#automated-verification). Standalone asset guard: [build.rs](../../apps/desktop/src-tauri/build.rs) rejects release builds without Tauri custom-protocol and tracks launcher icons for native resource recompilation. Always use the Tauri CLI through npm run build; direct cargo release without custom-protocol retains the development URL. Build outputs and dependencies are excluded from source orientation.

## Camera capture and OCR

Requests: photograph into quanta, scan text, Attach/OCR/Camera/Paste icons. Phone entry/permission/draft owner: [TunnelApp](../../apps/mobile/src/TunnelApp.tsx). Capture readiness, app-background handling, duplicate-shutter guard and cache cleanup: [CaptureCamera](../../apps/mobile/src/CaptureCamera.tsx). Crop review/handles/Reset/Retake/Continue: [OcrCrop](../../apps/mobile/src/OcrCrop.tsx). Upright normalized geometry and letterbox fitting: [crop helpers](../../apps/mobile/src/crop.ts), checked by [crop tests](../../tests/crop.test.ts). Native recognizeText validates the crop and decodes/crops before OCR. `CaptureCamera` disables Expo shutter animation in both modes and retains the OCR cache photo until review ends. Text merge/UTF-8 validation: [camera-draft](../../apps/mobile/src/camera-draft.ts), checked by [OCR draft tests](../../tests/camera-draft.test.ts). Durable photo import/rejected-import cleanup: [files](../../apps/mobile/src/files.ts). Android bundled Latin-script ML Kit recognizer and cache-only URI validation: [TunnelLinkModule](../../apps/mobile/modules/tunnel-link/android/src/main/java/app/tunnel/link/TunnelLinkModule.kt), exposed through [connection](../../apps/mobile/src/connection.ts); dependency in the module’s `android/build.gradle`. Typecheck and Android native release compilation are automated; H16/H17 camera/OCR/crop/device/visual checks stay with the user. No desktop/iOS OCR. See [usage](../../docs/usage.md) and [attachment persistence](../data/model.md#attachment-storage-and-sharing).
